Project Description:
This project explores the four types of gRPC RPCs:

Unary RPC:
A simple request-response model where the client sends a single request, and the server returns a single response. Example: Retrieving user details.

Server Streaming RPC:
The client sends a single request, and the server responds with a continuous stream of data. Example: Streaming real-time weather updates.

Client Streaming RPC:
The client sends a stream of requests, and once all data is sent, the server returns a single response. Example: Uploading a series of log entries.

Bidirectional Streaming RPC:
Both the client and server send a continuous stream of messages to each other. Example: Real-time chat application where both parties send and receive messages simultaneously.
